# telegram-plugin

Read your own Telegram account from an AI coding agent: find a chat, read its
messages, search across chats, download attachments — and send a message only
when you explicitly turn that on.

Ships as an MCP server plus plugin manifests for Claude Code, Codex and Cursor.
Any other MCP host can point at the same launcher directly.

Status: in development.
